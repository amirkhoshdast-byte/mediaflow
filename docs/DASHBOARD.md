## ۱. هدف داشبورد

> مدیر حساب در **۳۰ ثانیه** بفهمد: چه چیزی مهم است، چه پیش‌نویسی منتظر **تصمیم** اوست (پرریسک‌ها اول)، چه مناسبتی نزدیک است، و همان‌جا تأیید یا ویرایش کند.

## ۲. مشکل امروز

صفحه‌ی اول چهار لایه‌ی هم‌وزن دارد (نوار بالا با ۸ دکمه، مرور هوشمند، سه ستون، شش صفحه‌ی جانبی). یک سیگنال در سه جا دیده می‌شود، پیش‌نویس هم در استودیو و هم در صف تکرار می‌شود، و «چه چیزی منتظر من است؟» یک‌جا نیست. در موبایل تأیید پشت دو کلیک است.

### «امروز» (صفحه‌ی اول، دسکتاپ)

```
┌─ نوار وضعیت: پست ۱/۳ · ریپلای ۰/۵ · پرریسک باز ۲ · منابع سالم ۱۴/۱۶ ─────────────┐
│ منتظر تصمیم شما (۵)                         │ فرصت‌های راهبردی امروز                 │
│ ┌───────────────────────────────────────┐   │  ورود فوری · عنوان … [امتیاز ۹۱]       │
│ │ ⚠ پرریسک · محور: فناوری و فرهنگ       │   │  برنامه‌ریزی · عنوان … [۷۲]            │
│ │ متن پیش‌نویس (ویرایش در جا)            │   │ ──────────────────────────────────── │
│ │ لحن ۷۴ · ۲ مغایرت    [تأیید] [ویرایش] │   │  مهم‌ترین تحولات امروز (۱۰ تا)          │
│ └───────────────────────────────────────┘   │ ──────────────────────────────────── │
│ (پرریسک اول، بعد خودکارها، بعد بقیه)          │  رویدادهای ۷ روز آینده  ·  ترازوی محورها│
└──────────────────────────────────────────────────────────────────────────────────┘
```

- **ستون راست (عریض): «منتظر تصمیم شما».** تنها جایی که تصمیم گرفته می‌شود (ویرایش در جا، دلیل پرریسک، خلاصه‌ی بررسی لحن، تأیید/رد).
- **ستون چپ:** فرصت‌های راهبردی (۳ تا ۵ مورد با وضعیت ورود فوری/برنامه‌ریزی)، مهم‌ترین تحولات، رویدادهای ۷ روز آینده از تقویم، ترازوی محورها (سهم واقعی در برابر هدف).
- **موبایل:** همان بخش‌ها زیر هم، نوار پایین با ۴–۵ آیکن.

### «پیش‌نویس‌ها»
تب‌ها: همه · ⚠ پرریسک · پیشنهاد خودکار · تأییدشده · منتشرشده. فهرست یک ستون؛ ویرایشگر/استودیو **کشوی کناری**. «پیشنهاد جدید» بالای صفحه (موضوع یا فرصت، مخاطب، زبان، لحن، قالب).

### «رصد»
فهرست کارت‌های موضوع (فیلتر: منطقه، دسته، وضعیت فرصت، منبع، تاریخ؛ جست‌وجو)، «افزودن خبر/توییت»، نوار سلامت منابع.

### «تقویم»
نمای ماهانه (شمسی اصلی، میلادی فرعی) با مناسبت‌های ملی و جهانی و رویدادهای دستی؛ هر روز: وضعیت آماده‌سازی و پیش‌نویس‌های برنامه‌ریزی‌شده.

## ۵. جریان‌های کاربر

1. **صبح (۳۰ ثانیه):** «امروز» ← نوار وضعیت ← «منتظر تصمیم» (پرریسک اول) ← تأیید/ویرایش ← فرصت‌های راهبردی ← رویدادهای ۷ روز.
2. **از فرصت تا انتشار:** فرصت «ورود فوری» ← (خودکار یا دستی) ۳ پیش‌نویس با محور و دلیل ← بررسی لحن خودکار ← تأیید ← انتشار دستی در X ← «ثبت انتشار» (+ پیوند پست). ارزیابی نتیجه در X Analytics.
3. **پرریسک:** برچسب و دلیل ← مغایرت‌ها ← ویرایش یا «اعمال پیشنهاد» ← تأیید با پرسش صریح. تلگرام از پیدایش آن خبر می‌دهد.
4. **برنامه‌ریزی:** تقویم ← مناسبت نزدیک ← ساخت پیش‌نویس برای آن روز.
5. **نگهداری هفتگی:** منابع (خطاها)، خط قرمزها، ترازوی محورها و بانک پیام.

## ۶. الزامات غیرکارکردی

- راست‌به‌چپ کامل، ویژگی‌های CSS منطقی، تاریخ شمسی اصلی.
- دسترسی‌پذیری: صفحه‌کلید، فوکوس دیدنی، کنتراست ≥ ۴٫۵، `prefers-reduced-motion`.
- سرعت: «امروز» < ۲ ثانیه؛ کارهای طولانی با نشانگر پیشرفت.
- موبایل: تأیید یک پیش‌نویس حداکثر در ۲ لمس.
- هر ویجت حالت خالی، بارگذاری و خطای روشن دارد.
- هیچ کلیدی در رابط نمایش داده نمی‌شود.
