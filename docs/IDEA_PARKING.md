# پارکینگ ایده‌ها

ایده‌ها و بدهی‌های فنی که در فاز جاری نمی‌گنجند. هر مورد فقط با حذف یا به‌تعویق‌انداختن چیز دیگری وارد فاز می‌شود.

- همگام‌سازی اختیاری پایگاه دانش با Obsidian (SPEC §5؛ در فهرست تحویل‌های فاز ۱ نیست).
- بهترین زمان انتشار (SPEC §5)؛ به داده تعامل واقعی نیاز دارد و پیش از فاز ۲ و ۳ معنا ندارد.
- شناسه‌های تکراری عنوان در صفحه اصلی (`mon-h`، `stu-h`، `pipe-h`)؛ چیدمان دسکتاپ و موبایل هر دو در DOM هستند. با `useId` یا رندر شرطی رفع شود.
- اجرای معیار «docker compose up روی سرور تمیز» روی یک سرور واقعی (تاکنون فقط روی Mac توسعه).
- رابط تاریخچه و بازگردانی نسخه‌های پیش‌نویس (حذف‌شده از فاز ۱ به تصمیم مالک؛ داده در `DraftVersion` ثبت می‌شود).
- حجم گفت‌وگو و رشد ترند (نیازمند X API پولی؛ Premium+ این را نمی‌دهد).
- ماژول ۸ (عملکرد و نفوذ) و ماژول ۹ (تعاملات): حذف‌شده به تصمیم مالک چون X خودش آمار و تحلیل می‌دهد؛ دوباره باز شود اگر X API گرفته شد.
- کتابخانه/آرشیو محتوا با دارایی رسانه‌ای و تشخیص تکراری (ماژول ۶ فقط تقویم است).
- نمای اجرایی فقط‌خواندنی برای رئیس سازمان (R4).
- قالب‌های Visual و Video Script (R4).
- RAG روی مواضع قبلی با امبدینگ (بانک پیام دست‌نویس جایگزین آن است).
